# Dataset

This folder contains the dataset used for the Online Course Recommendation System.

## Dataset Details

- Total Records: 100,000
- Features: 14
- Users: 43,242
- Courses: 20

## Dataset Attributes

- User ID
- Course ID
- Course Name
- Instructor
- Course Duration
- Certification Offered
- Difficulty Level
- Rating
- Enrollment Numbers
- Course Price
- Feedback Score
- Study Material Available
- Time Spent
- Previous Courses Taken

The dataset was used for exploratory data analysis, feature engineering, and recommendation model development.
